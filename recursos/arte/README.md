Esta imagen ya no se carga. El fondo actual usa una fotografía real de Xalapa en `recursos/fotos/panorama_xalapa.jpg`. Para sustituirla, cambia `paisaje` y actualiza `credito_paisaje` en `recursos/arte_xalapa.tres`.

## Prompt utilizado

Use case: illustration-story. Asset type: temporary background illustration for a 2D game set in Xalapa, Mexico. Create a wide 3:2 landscape illustration of a fantastical Xalapa hillside, a distant pale blue volcanic peak, misty sage green hills, colorful colonial houses with terracotta tiled roofs, a cream cathedral tower, dense trees and a stone arched bridge. Style: refined hand-painted gouache storybook background, simplified strong silhouettes, warm ivory paper, soft muted eucalyptus greens, dusty coral, ochre and blue-gray, subtle dry brush texture. Composition: panoramic distant scenic view, pale open sky in top 35 percent, city in the middle and bottom, no foreground props or characters, no ground platform, no hard outlines, no text, no borders, no watermarks. Low contrast and restrained detail so a game character and UI remain readable. High quality game environment concept art, quiet daylight.
