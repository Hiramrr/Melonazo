# Fuente del juego

`Fredoka.ttf` es la fuente de toda la interfaz. Va incluida en el proyecto para que el juego se vea igual en Windows, macOS y Linux sin depender de las fuentes instaladas en cada equipo.

- Autores: The Fredoka Project Authors (https://github.com/hafontia/Fredoka-One).
- Fuente: Google Fonts, `ofl/fredoka/Fredoka[wdth,wght].ttf`.
- Licencia: SIL Open Font License 1.1, incluida en `OFL.txt`.
- Es una fuente variable: el tema (`interfaz/tema_xalapa.tres`) elige el grosor con `FontVariation` (eje `wght`, de 300 a 700).

La fuente no incluye flechas, estrellas ni símbolos de reproducción. Esos dibujos son sprites PNG en `recursos/iconos/`.
