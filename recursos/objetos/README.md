# Objetos de 64 × 64

Sprites PNG con transparencia. Generados con la herramienta integrada de imágenes, tomando como referencia de estilo la paloma proporcionada por el usuario. Cada archivo se adapta a 64 × 64 mediante vecino más cercano, conservando su transparencia.

La paloma original está en `../poderes/pajaro.png`, orientada hacia la izquierda para coincidir con su movimiento.

Los rivales usan cada objeto una vez sin modificar su disponibilidad para el jugador. No hay recarga compartida de papalotes. El uso del jugador conserva los efectos de consumo o destrucción correspondientes.
