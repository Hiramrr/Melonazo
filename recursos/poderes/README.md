# Imágenes provisionales de poderes

Imágenes 3D de [Microsoft Fluent Emoji](https://github.com/microsoft/fluentui-emoji), usadas mientras se crea el arte propio. Copyright Microsoft Corporation. Licencia MIT, incluida completa en [LICENSE.txt](LICENSE.txt).

Los PNG originales tienen fondo transparente y se incluyen sin modificaciones. Se descargaron de la revisión `1ffb34c752ecf5d402f04cfb4b392c77f57c54bc`. El juego los escala al dibujar, conserva sus nombres y no necesita conexión.

Para poner los assets definitivos, sustituye estos cuatro archivos. Si cambian los nombres o el formato, actualiza `TEXTURAS` en `mundo/ayudas/poder.gd`. La ruta y el pasaporte usan esas mismas texturas. Conserva el fondo transparente y un lienzo cuadrado para mantener las proporciones.
